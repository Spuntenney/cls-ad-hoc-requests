# AdHoc Requests

CLS Living app shell for AdHoc Requests. This is a branded layout and routing scaffold. Feature pages are placeholders.

## Setup

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173). The app loads the authenticated layout directly.

## Logo

The sidebar uses the CLS Living knockout stacked logo. Set `VITE_CLS_LIVING_LOGO_URL` to override it. See `.env.example`.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — typecheck and production build
- `npm run preview` — preview the production build
